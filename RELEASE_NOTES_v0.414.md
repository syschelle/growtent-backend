# GrowTent Backend v0.414 – Login and 2FA hardening (DE/EN)

- **Traefik-safe login protection:** Failed login counts are scoped to a username+client-IP pair, not to a username or the proxy IP globally. This avoids a proxy-wide account lockout triggered by six unrelated failures. The existing lockout threshold and window remain configurable.
- **Trusted forwarding only:** Uvicorn no longer automatically trusts proxy headers. `GT_TRUSTED_PROXY_CIDRS` allows forwarding only from explicit trusted proxy peers; the application resolves the nearest untrusted hop, ignoring spoofed prefix entries. The default is an empty allowlist. When no trusted proxy is configured, login counts use the immediate TCP peer, which might be Traefik.
- **Account enumeration hardening:** Unknown accounts trigger an Argon2id dummy password verification; generic login errors remain unchanged.
- **One-use 2FA codes:** Successful login, administrator step-up and 2FA enrollment atomically record the accepted TOTP time step in PostgreSQL. The same time step cannot be used again, including across process restarts. A newly rotated TOTP secret gets a fresh counter. **When performing step-up immediately after logging in with 2FA, use the next code generated by the authenticator.**
- **Database:** The idempotent startup migration creates `app_totp_replay` with no manual intervention; existing users, passwords and encrypted TOTP seeds remain unchanged. No changes to camera, Shelly, ESP, irrigation, VPD, HMAC or JSON/ZIP exports.
- **Testing:** New isolated unit and PostgreSQL integration tests for proxy trust, account/client lockout isolation, dummy verification and TOTP replay; full Python, Node and browser regressions. Live Traefik, Docker rebuild, PostgreSQL deployment and actual 2FA apps still require verification.
