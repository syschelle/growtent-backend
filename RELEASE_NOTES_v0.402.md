# GrowTent Backend v0.402 – Original and HDR-style snapshot in analysis ZIP

- Keep the unchanged historical JSON export and the original native-resolution `camera.jpg` in the analysis ZIP. Add a **second** `camera-hdr.jpg` derived from the same camera frame using gentle local shadow/highlight tone mapping. One camera request only; no additional RTSP stream, exposure captures or controller commands.
- This is **single-frame HDR-style enhancement**, not true multi-exposure HDR. The algorithm cannot recover details already clipped by the camera; it preserves chroma, avoids aggressive sharpening and stores the result as a high-quality JPEG (quality 94, 4:4:4). The original JPEG remains byte-identical as in v0.401.
- Keep the HDR output at native resolution through 16 MP (including 4K); exceptionally large frames are downsampled proportionally with LANCZOS. Both images independently respect the 20 MB image limit; ZIP size can increase accordingly.
- Extend `camera_snapshot.hdr` with status, filename, actual HDR image dimensions and `method: "single_frame_tone_mapping"`. Preserve the original `camera_snapshot` fields. On HDR processing failure, keep the original JPEG and add bilingual `camera-hdr-unavailable.txt`; camera/network failure still exports JSON with `camera-unavailable.txt`.
- Update DE/EN Dashboard export hint and analysis export documentation; retain legacy JSON endpoint, data formats, permissions and 1 MB historical JSON limit. No database, firmware, ESP/Shelly control, GrowGuide or VPD changes.
- In the fullscreen camera viewer, add an on-demand Original/HDR toggle (DE/EN) over the image. HDR uses the same single-frame adjustment as the export and can be switched during smart zoom. Default normal preview remains byte-identical; HDR requests are throttled to reduce CPU. Correct narrow-window header/image-area sizing. Fullscreen images are not saved or added to the history.
- Local verification: 319 Python regressions (PostgreSQL-only integration tests excluded), five JavaScript suites, and Python Chromium checks for the export dialog and fullscreen viewer in DE/EN with mobile width and 200% smart zoom. Docker build and live camera validation remain to be done.
