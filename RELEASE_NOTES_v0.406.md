# GrowTent Backend v0.406 – Cleaner camera pot markers (DE/EN)

- **Outside the camera picture:** Administrators now see the **Positionen bearbeiten / Edit positions** control in a separate narrow toolbar above the camera. While editing, **Speichern / Save** and **Abbrechen / Cancel** appear there too. No positioning controls cover the plants.
- **Inside the camera picture:** Only **Töpfe / Pots** remains as an overlay toggle. The removed **Sorten / Strains** toggle and all visible strain text are gone. Positioned pots appear as small coloured circles containing **1**, **2** or **3**. Zoom, Original/HDR and marker dragging/keyboard adjustment remain available.
- **Analysis ZIP:** `camera-marked.jpg` now displays only numbered circles **1–3**, without strain labels or boxes. `camera.jpg` stays byte-identical; `camera-hdr.jpg` and the optional marked image still share a single source frame. The original per-tent `pot_strains`, `pot_positions` and the image metadata remain in the JSON (JSON-only and ZIP), so external analysis can still identify each plant.
- **Access and compatibility:** Only administrators can edit saved coordinates; guests can toggle/view saved markers but do not receive editor controls. No new database migration, ESP commands, RTSP capture, HMAC action, watering/VPD behavior or API change is introduced.
- **Verification:** 337 Python tests (excluding optional PostgreSQL integration), five JavaScript suites, Chromium DE/EN/admin/guest/HDR/mobile drag/save/cancel tests, ZIP and current-only release validation. PostgreSQL, Docker and real-camera checks remain deployment tests.
